  • 오프라인 오디오 파이프라인: PyAudio 수집 스트림에 SpeechRecognition 및 Windows SAPI5 COM 스레드 관리를 적용해, CPU 및 VRAM 부담을 주지 않는 로컬 마이크 자동 캘리브레이션 및 음량 조절 모듈을 연동했습니다.
  • 작업 흐름 비방해(Clipboard Bypass): 호출어("안티그래비티", "gravity") 감지 후 음성 명령 텍스트를 클립보드를 오염시키지 않고 HTTP API를 통해 IDE 에이전트 입력 패널에 직접 문자 입력 형태로 실시간 주입한 뒤, 포커스를 작업 창으로 즉시 반환시킵니다.
핵심 기능 및 사용자 경험

호출어("안티그래비티", "gravity") 감지 시 백그라운드 리스너가 즉각 반응하여 음성 명령을 실시간 제어 스크립트로 치환하며, 사용자의 작업 흐름을 깨뜨리지 않는 비침습적 클립보드 우회 주입(Bypass) 기법을 구현했습니다. 또한 VS Code 전용 GUI 설정 패널을 통해 로컬 마이크 감도 및 포트 설정을 손쉽게 제어할 수 있습니다.

Goal-Conditioned Reachability Logit Masker (GCLM)

LLM 제약 디코딩 시 데드엔드 트랩 진입과 토큰 예산 초과로 인한 문법 절단을 원천 차단하는 O(1) 시간 복잡도의 목표 조건부 도달가능성 로짓 마스킹 엔진입니다.

작업 기간

2026. 08 - 2026. 09

역할 (AI Research & Open Source)

이론적 정식화(Time-Bounded Backward Reachability), 벡터화 역방향 BFS 도달가능성 알고리즘 설계, Hugging Face LogitsProcessor 호환 모듈 개발, 데드엔드 회피 벤치마크 및 논문 작성

1인 연구 및 오픈소스 개발

FSM 컴파일러 설계부터 오프라인 텐서 빌더, O(1) 런타임 인플레이스 마스커 구현, 학술 논문(PDF) 작성 및 Hugging Face 패키지 배포까지 전 과정 1인 주도 개발

문제 정의 및 기존 기법(Outlines / SGLang)의 한계

기존의 Outlines, SGLang 등 전방향(Forward) DFA 기반 제약 디코딩 마스커는 현재 상태에서 전이 가능한지만 검사합니다. 이로 인해 생성 도중 빠져나올 수 없는 데드엔드 트랩(Dead-End Trap)에 진입하거나, 토큰 예산(T_max) 소진 시 종결 문법(예: JSON 닫는 괄호 '}')이 완성되지 못하고 잘려버려(Truncated Syntax) 파싱 에러가 발생하는 근본적인 한계가 존재했습니다.

핵심 아키텍처 및 구현 방식
  • 시간 바운드 역방향 BFS 도달가능성 테이블 구축: 생성 시작 전, FSM 전이 관계와 최대 토큰 예산(T_max)을 기반으로 수락/목표 상태(S_goal)로부터 역방향 BFS를 완전 벡터화(Vectorized)하여 (T_max + 1, |S|) 크기의 텐서 R을 사전 연산합니다.
  • Strict O(1) 런타임 인플레이스 마스킹: 디코딩 매 스텝마다 남은 토큰 수(T_rem) 내에 목표 상태에 도달할 수 없는 전이 토큰을 엄격한 O(1) 벡터화 인덱싱으로 즉시 판별하여 -inf로 인플레이스 마스킹(평균 오버헤드 0.1ms 미만)합니다.
  • 토큰 예산 초과 전 조기 문법 종결 강제: 토큰 예산이 소진되기 직전 유효한 문법 종결 경로만을 강제함으로써, 토큰 제약 환경에서도 문법 파싱 실패율 0%를 달성합니다.
  • 상태 수 무관 제로 런타임 종속성 (Zero Runtime Dependence): FSM 상태 수(|S|)가 증가하더라도 런타임 토큰당 처리 오버헤드가 증가하지 않고 O(1) 텐서 룩업으로 처리되어 LLM 추론 지연 시간(Latency)에 영향을 미치지 않습니다.
성과 및 오픈소스 배포
